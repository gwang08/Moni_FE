# Moni Design Context

This document defines the visual and experiential soul of Moni. It guides all UI/UX decisions to ensure a cohesive, high-quality, and "impeccable" interface that avoids generic AI aesthetics.

## Design Context

### Users
- **Primary**: IELTS aspirants (students and working professionals) who need a reliable, high-stakes practice environment.
- **Context**: Often stressed, focused, and time-constrained. They need an interface that reduces cognitive load during practice but provides rich, encouraging feedback during review.
- **Jobs to be Done**: Simulate real test conditions, track progress via data visualization, and improve specific skill weaknesses through AI-driven insights.

### Brand Personality
- **Precision**: Every detail matters. Alignment, typography, and timing must feel as rigorous as the IELTS exam itself.
- **Momentum**: The UI should feel fast and forward-moving. Use motion to celebrate small wins and guide the user through the learning journey.
- **Warmth**: Unlike cold, traditional testing software, Moni should feel like a supportive mentor. Approachable but professional.

### Aesthetic Direction
- **Visual Tone**: **"Refined Editorial"** meets **"High-Tech Studio"**. 
- **Typography**: Moving away from the generic "Geist/Inter" monoculture. Pairing a sharp, authoritative serif for headings (to evoke the "Cambridge" academic feel) with a highly legible, modern sans-serif for UI/UX elements.
- **Theme**: Primarily Light Mode for focus and readability (matching paper-based origins of IELTS), but with a sophisticated, low-contrast "Midnight" Dark Mode for late-night study sessions.
- **Color Palette**: 
    - **Primary**: Deep Teal (`oklch(55% 0.15 160)`) as the anchor.
    - **Accents**: Energetic Coral or Golden Amber for calls-to-action and "celebration" moments.
    - **Neutrals**: Warm Grays (`oklch(x 0.01 160)`) to ensure the brand hue bleeds into every surface.

### Design Principles
1. **Reduce Friction, Not Challenge**: The interface should get out of the way of the content. Practice is hard; using the app shouldn't be.
2. **Data with Dignity**: Progress charts and scores should feel like achievements, not just numbers. Use elegant visualizations (Recharts) with purposeful color coding.
3. **Intentional Motion**: Use staggered reveals and smooth transitions to reduce the "jank" of loading states, making the app feel like a single, continuous experience.
4. **Anti-Slop**: No generic "gradient text" or "side-stripe cards". Use depth, subtle borders, and intentional white space to create hierarchy.
